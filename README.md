# ITEST Frontend Shell (Vue 3 Modular Architecture)

Repository giao diện Frontend độc lập thuộc hệ sinh thái **ITEST Platform (Enterprise IoT & Automation)**. Được tách rời hoàn toàn khỏi `itest-system` (NestJS backend), hỗ trợ kiến trúc plugin toàn diện (Full-stack plugins), cơ chế build-time Vite plugin registry generator, bảo vệ giao diện chống lỗi theo chuẩn SOP `CModuleBoundary`, và đóng gói Docker container Nginx độc lập.

---

## 🚀 Tính Năng Chính

- **Độc Lập & Nhẹ Nhàng**: Hoàn toàn tách biệt khỏi mã nguồn backend NestJS. Chạy trên Vue 3 (Composition API), Vite 6, Pinia, Vue Router 4, Element Plus.
- **Frontend Plugin SDK (`@itest/frontend-sdk`)**: Chuẩn hóa hợp đồng tương tác giữa Shell và các plugin mở rộng (Route, Menu Sidebar, Dashboard Widgets, Extension Slots, EventBus, API Client).
- **Build-time Plugin Registry Generator**: Tự động phát hiện các plugin có phần frontend, kiểm tra tương thích phiên bản SDK, sinh mã TypeScript `src/generated/plugin-registry.ts` mà không cần chỉnh sửa thủ công vào `App.vue` hay `main.ts`.
- **Phòng Vệ Giao Diện (Defensive Rendering SOP)**: Bọc toàn diện `CModuleBoundary` cho router-view và từng widget, đăng ký `app.config.errorHandler` toàn cục, ngăn chặn triệt để lỗi của một plugin làm sập toàn bộ ứng dụng (chống kẹt trắng trang, có nút Retry phục hồi).
- **Hỗ Trợ Full-Stack Plugin Đơn Vị**: Hỗ trợ cấu trúc plugin chứa cả `backend/` (NestJS) và `frontend/` (Vue 3) được quản lý chung một repo (`itest-plugins/plugins`), nhưng được build độc lập và chính xác bởi từng hệ thống.
- **Docker Production Ready**: Cung cấp multi-stage Dockerfile và cấu hình Nginx tối ưu hóa SPA fallback, gzip compression và proxy chuyển tiếp `/api` đến backend container trên cùng mạng Docker `itest-network`.

```text
itest-frontend/
├── packages/
│   └── frontend-sdk/                 # @itest/frontend-sdk (Types, EventBus, Context, Registry)

│   ├── layouts/                      # MainLayout.vue (Dynamic Sidebar), AuthLayout.vue
│   ├── plugin-system/                # SDK Loader, Plugin Manager
│   ├── router/                       # Vue Router 4 & Dynamic Route Guard
│   ├── stores/                       # Pinia Stores (auth.ts, plugin.ts)
│   ├── views/                        # Core Views (Login, Dashboard, Plugins, NotFound)
│   ├── App.vue                       # Root Component bọc bởi CModuleBoundary
│   ├── main.ts                       # Entrypoint khởi tạo Vue App & Global Error Handler
│   └── vite-env.d.ts
├── plugins/                          # Thư mục đồng bộ frontend của các plugin
├── docs/                             # Hướng dẫn chi tiết dành cho AI Agent & Developers

├── package.json
```

## 🛠️ Hướng Dẫn Cài Đặt & Phát Triển

### 1. Yêu Cầu Môi Trường
- **Node.js**: v20.x hoặc v22.x+
- **pnpm**: v9.x hoặc v10.x+ (`corepack enable && corepack prepare pnpm@latest --activate`)

### 2. Cài Đặt Phụ Thuộc & Build SDK
```bash
# Cài đặt toàn bộ dependencies trong workspace
pnpm install

# Biên dịch Frontend Plugin SDK
pnpm run sdk:build
```

### 3. Đồng Bộ Plugin & Sinh Registry
```bash
# Quét thư mục ../itest-plugins/plugins, đồng bộ các plugin có frontend và tạo registry
pnpm run plugins:update
```

### 4. Chạy Môi Trường Phát Triển
```bash
pnpm run dev
```
Giao diện sẽ chạy tại `http://localhost:5173`. Mọi request `/api/*` sẽ được Vite proxy tự động về `http://localhost:3000`.

### 5. Biên Dịch Bản Build Production
```bash
pnpm run build
```
Kết quả được xuất ra thư mục `dist/` với mã nguồn tối ưu hóa, sẵn sàng deploy lên bất kỳ static server nào.

## 🐳 Triển Khai Với Docker

Frontend được đóng gói thành container Nginx độc lập, kết nối chung mạng `itest-network` với backend NestJS và cơ sở dữ liệu PostgreSQL.

```bash
# Khởi động container itest-frontend
docker compose up -d --build
```

- Cổng truy cập mặc định: `http://localhost:8080`
- Cấu hình Nginx tự động proxy các yêu cầu `/api/` đến container `itest_core_backend:3000`.
