# Font Awesome Configuration

Detected and configured by Font Awesome agent skills for iTest 2.0.

## Integration

- **Method:** Vue 3 components via `@fortawesome/vue-fontawesome`
- **Version:** 7.3.1 (SVG Core), 3.3.3 (vue-fontawesome)
- **License:** Free
- **Families:** classic (solid, regular)

## Defaults

- **Style:** solid (`fas`)
- **Family:** classic

## Import Pattern

- Library registration: `library.add(fas, far)` in `src/main.ts`
- Global Component: `<font-awesome-icon :icon="['fas', 'icon-name']" />` and `<FaIcon :icon="['fas', 'icon-name']" />`
- Universal Icon Wrapper: `src/components/shared/CyberIcon.vue` seamlessly maps system/plugin icon keys to Font Awesome icons.
